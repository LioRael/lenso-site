# Source-content fixture: limitations

The publisher, source revision, and document digests here are signed test
metadata. The `example.test` archive URLs are placeholders; no source archive
or editor behavior is published by this fixture. The Site verifies the
Markdown body at build time but does not fetch or inspect source archives.

Editable copies belong to the App owner. A later catalog revision must not
overwrite their changes. Remove a copied directory through the App's source
control process after reviewing any separate extension selection.
