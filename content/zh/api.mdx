## 实验、开发中与平台限制

- oRPC v2 固定 `2.0.0-beta.42`，属于预发行协议，发布 Web 0.1.0 仍使用 v1。
- Core 配置及 Web `/bun` 为已实现源码预览，尚不在相同版本的 npm 包中。
- Log/OTel 有源码实现，但本次 registry 404。Workers 默认使用平台原生遥测，不能假设 Bun SDK 行为。
- Manage 没有独立公开包或命令；显式应用操作才是当前可用入口。配置中心、订阅/hot reload、Observe query CLI 尚未提供。
- Tasks 的持久队列实现是 PostgreSQL；D1/R2 绑定归平台所有，不能当作 Bun client 关闭。
- browser 入口不导出 startApp；服务端资源、secret 与身份适配器不得进入客户端包。
