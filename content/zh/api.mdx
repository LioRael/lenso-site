## 已发布、实验与尚未提供的边界

- 上述精确包均已发布，公开入口与符号已经按真实 tarball 核对；这不授予任何应用级授权或部署权限。
- oRPC v2 固定预发行 2.0.0-beta.42；客户端与服务端必须匹配。Workers 原生 tracing 入口是独立实验路径，不能假设与 Bun OTel SDK 行为相同。
- Manage 已提供有限操作 adapter、agent 工具与可选 oRPC router；没有内置 Console UI、持久审批/audit、调度、回滚或自动配置读写。可信 binding、operation admission 与共享服务对象策略缺一不可。
- 配置中心、订阅/hot reload、Observe query CLI 尚未提供。配置来源可替换，底层解析可手动使用，不要求 Web。
- 当前持久队列为 PostgreSQL。D1/R2 是借用的平台 binding；Bun filesystem、DB client 与 Engine 不属于 Worker 运行时图。
- Browser 入口不导出 startApp；服务端资源、secret 与身份适配器不进入前端 bundle。Storage/Tasks 没有公开 migration 子路径，不猜测内部 import。
