---
title: Module Console UI
description: Ship module-owned Console pages as verified isolated web artifacts.
---

A Module may contribute Console navigation and pages, but executable UI never
runs inside the Console Shell JavaScript realm. The manifest declares the
surface; the same immutable Module Release binds its verified UI artifact.

## Declare an isolated surface

```rust
use lenso::{
    ConsoleNavigation, ConsoleSurface, ConsoleSurfacePresentation,
    ConsoleWorkspaceRef, ModuleManifest, CONSOLE_BRIDGE_PROTOCOL,
};

pub fn manifest() -> ModuleManifest {
    ModuleManifest::builder("crm")
        .capabilities(vec!["crm.contacts.read".to_owned()])
        .console(vec![ConsoleSurface {
            name: "contacts".to_owned(),
            label: "Contacts".to_owned(),
            route: "/crm/contacts".to_owned(),
            presentation: ConsoleSurfacePresentation::Isolated {
                entry: "contacts".to_owned(),
                bridge_protocol: CONSOLE_BRIDGE_PROTOCOL.to_owned(),
            },
            icon: Some("briefcase".to_owned()),
            required_capabilities: vec!["crm.contacts.read".to_owned()],
            navigation: Some(ConsoleNavigation {
                workspace: ConsoleWorkspaceRef {
                    id: "crm".to_owned(),
                    label: "CRM".to_owned(),
                    icon: Some("briefcase".to_owned()),
                },
                group: None,
                order: Some(10),
            }),
        }])
        .build()
}
```

The Module Release must contain a `ConsoleUiArtifact` with format
`isolated_web`, the exact artifact locator and SHA-256 digest, an entry mapping
such as `{ name: "contacts", path: "index.html" }`,
`lenso.console-bridge.v1`, requested permissions, and provenance. A release is
invalid when an isolated surface has no matching artifact entry.

Create a Module with this surface using:

```sh
lenso module create crm --with-console-ui
lenso module dev --console-ui
```

## Runtime boundary

The Console Service downloads the complete selected artifact set only through a
reviewed composition operation. It verifies every digest and records an atomic
composition receipt. The Shell then loads each page in a sandboxed iframe and
grants only the reviewed subset of requested Bridge operations for the exact
Module Release and artifact digests.

An artifact may use `@lenso/console-bridge` to exchange structured messages with
the Shell. It cannot receive ambient credentials, import Shell internals, use
same-origin storage, or call a managed Service directly.

There is no `/console/extensions/*` registry, same-origin JavaScript bundle,
`@lenso/runtime-console-api`, or separate Console package installation command.
UI lifecycle follows ordinary `lenso module install|update|disable|remove` and
`lenso console composition plan|apply` operations.

## Missing UI evidence

If the manifest declares a surface but the selected artifact is absent,
unverified, or lacks a grant, Console reports that composition gap. It does not
silently load a package or execute an unreviewed fallback.
