title: Repository map
description: Route changes to the repository that owns the Interface and its evidence.
---

The Rust platform has been consolidated into `LioRael/lenso`; JavaScript and
TypeScript distribution surfaces live in `LioRael/lenso-js`. The former
`lenso-engine`, `lenso-runtime-rust`, `lenso-bun-adapter`, `lenso-protocols`,
`lenso-cli`, and `lenso-web` repositories are migration sources, not current
ownership boundaries. Console owns its page SDK/compiler and Agent owns Tool
conventions. See [Engine](/docs/core/engine-dx).

| Repository | Current ownership |
| --- | --- |
| `LioRael/lenso` | Rust Core, Engine, Runtime Drivers and Adapters, Rust CLI, protocol tooling, Web integration, and canonical ADRs |
| `LioRael/lenso-js` | Bun/Node SDKs, TypeScript Host authoring, npm CLI launcher, and generated Web client |
| `LioRael/lenso-examples` | executable examples and product-neutral fixtures |
| `LioRael/lenso-auth-plugin` | portable Auth Capability and assertion SDK |
| `LioRael/lenso-otel-plugin` | removable OpenTelemetry Plugin |
| `LioRael/lenso-console` | local Console Shell, Agent identity catalog, selected-App context, same-origin integration, and the reference Console Host |
| `LioRael/lenso-projects-web-plugin` | Projects Web Endpoint Plugin and optional native Console Workspace contribution; the Projects Provider owns business facts and authorization |
| `LioRael/lenso-jobs-plugin` | durable single-step Jobs Capability, queue/lease/retry evidence, and the PostgreSQL persistence Adapter |
| `LioRael/lenso-site` | this versioned public documentation |

Dependencies point inward toward the portable core. A change that needs core to
import one of these concrete owners is usually at the wrong seam.

## Choosing an owner

- Graph, lifecycle, invocation, cancellation, readiness, or diagnostics
  semantics: core Kernel.
- Scheduling, time, joins, or host shutdown: Runtime Driver.
- Plugin generation, process/wire endpoint, or isolation: Execution Adapter.
- Product behavior, state, Auth, secrets, telemetry, or UI: ordinary Plugin.
- Console Shell, Agent identity selection, selected-App context, and integration: Console;
  project or other business facts and final authorization: the owning business
  Plugin and Provider.
- Durable queue, lease fencing, retry, and inspection evidence: Jobs Plugin;
  payload meaning and external-effect idempotency: the consuming business Module.
- Package edits, lock inspection, schema/codegen freshness, or Plan resolution:
  authoring tooling.

The CLI declares and prepares TypeScript/Bun Hosts; `lenso-host-runtime`
assembles the Rust Kernel and Bun/Process Adapters. See [TypeScript Host](/docs/core/typescript-host)
for the entrypoint and current limits.
