The current App tutorial is a **source-built local preview**. It does not
promise that the CLI or every generated dependency is available from a public
registry. The manual and coding-agent routes use the same App, commands, and
success checks.

## Tutorial: complete one browser request

[Create a local Web App](/docs/core/app-quickstart) selects the linked Web
starter explicitly with `--web`, runs the App, submits a greeting from the
browser, and checks the result of a second linked Plugin. Stop at the page's
dependency boundary if the exact source cohort cannot build.

## Tasks after the first result

| When you need to | Use |
| --- | --- |
| Find a Plugin and inspect its exact version and documentation | [Plugin directory](/plugins) |
| Change the App's selected Plugins and bindings | [Add Plugins to an App](/docs/core/plugin-composition) |
| Preview or adopt a signed npm package or editable source release | [Adopt signed npm or source content](/docs/core/adopt-signed-sources) |
| Configure an Instance, then disable or remove it | [Configure a Plugin](/docs/core/plugin-configuration) and [Plugin lifecycle](/docs/core/plugin-lifecycle) |
| Connect a React page to a typed public API | [React/Vite candidate path](/docs/core/react-vite-app) |
| Diagnose an App that does not resolve or start | [Inspect a failing App](/docs/core/inspect-an-app) |

The directory distinguishes signed releases from unsigned candidates. A
versioned document belongs to one exact Plugin ID and version; a candidate
page is not an installation instruction. The Site cannot decide whether a
release is compatible with your local App or authorize adoption for you.

The unsigned Web 0.4.5 entry is a migration-era example from the former
`lenso-web` repository; [current Web source](https://github.com/LioRael/lenso/tree/main/crates/lenso-web-ingress-plugin)
lives in the consolidated Rust repository.
