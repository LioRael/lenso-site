## Runtime Driver 检查表

真实 Driver 提供调度、wakeup、单调 timer、join、协作式取消与关闭转换。只通过
目标编译不是运行时证明；每个 Profile 都需要 scheduler、timer、readiness、
cancellation 与 shutdown smoke evidence。

## Execution Adapter 检查表

Adapter 持有：

- 提供给 Plan 校验的 execution-class 标识；
- Module factory 或 process generation；
- 强类型 endpoint 与 Adapter 特定 dispatch；
- framing、isolation 和资源所有权；
- 失败分类和 restart cleanup；
- 对已发布 Runtime Interface 的 conformance。
