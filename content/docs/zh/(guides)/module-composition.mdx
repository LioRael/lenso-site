---
title: App Definition
description: 选择 Module package 与 keyed Instance，而不手写派生的 Composition。
---

Module package 拥有生成的 Descriptor：provided Capability、Port、Operation、
execution class、配置 Schema 与 lifecycle。App Definition 只保存 App 意图：
选择哪些 package、Instance key、配置、lane，以及真实 provider 歧义的决定。

## 写意图，不写运行图

```json title="lenso.app.json"
{
  "schema_version": 1,
  "manifest": "Cargo.toml",
  "packages": {
    "example.orders": "orders-module",
    "lenso.secrets.env": "lenso-secrets-env-module",
    "lenso.web-ingress": "lenso-web-ingress"
  },
  "app": {
    "name": "orders",
    "modules": [
      { "key": "orders", "package": "example.orders" },
      {
        "key": "secrets",
        "package": "lenso.secrets.env",
        "configuration": {
          "references": { "database/url": "APP_DATABASE_URL" }
        }
      },
      {
        "key": "web",
        "package": "lenso.web-ingress",
        "configuration": { "bind_address": "0.0.0.0:8080" }
      }
    ],
    "decisions": []
  }
}
```

Resolver 从锁定 package 的 Descriptor 派生运行图。只有一个兼容 provider 时
自动闭合 binding；`one` 歧义才要求 App owner 决定；`many` provider 使用确定
顺序。Module 不能从全局 registry 查找未声明依赖。

## 事务化修改 App

```sh
lenso app add orders-module --definition lenso.app.json --version '^1.0' --dry-run
lenso app add orders-module --definition lenso.app.json --version '^1.0'

lenso app check --definition lenso.app.json
lenso app resolve --definition lenso.app.json \
  --output .lenso/resolved-plan.json

lenso app remove orders --definition lenso.app.json --dry-run
lenso app remove orders --definition lenso.app.json --uninstall
```

`app add` 与 `app remove` 把 package manifest、普通 lock 和 App Definition
作为一次事务修改。`app check` 验证锁定 package 与派生图；`app resolve` 为
产品自己的 Runner 或 Host 输出 canonical Plan bytes。作者界面不再提供通用
`run --plan` 命令。

## 把策略交给正确所有者

| 关注点 | 所有者 |
| --- | --- |
| 业务规则、migration、transaction | 所属 Module |
| Interface 类型与 Domain Error | Capability owner |
| package 选择、配置、lane、真实歧义 | App Definition |
| 派生 endpoint 与 binding | Resolver 输出 |
| 调度、cancel、shutdown | Runtime Driver 与 Kernel |
| HTTP、进程、浏览器或 Host failure 机制 | Execution Adapter 或协议 Module |

配置只保存逻辑 secret reference。移除产品关注点时，应只移除 Module 选择而不
修改 Kernel。替换 provider 会产生新 Plan 或 App Generation，而不是运行时发现。
