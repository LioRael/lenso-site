## 三块内容如何连接

```mermaid
flowchart LR
  C[核心框架\nPlugin + Capability + Host] --> W[Web\nEndpoint + Ingress]
  C --> A[Agent\nModel + Session + Tool]
```

Web 与 Agent 都是构建在同一套框架上的产品路径。它们的教程只解释下一步必需的
Core 概念，并链接到唯一的权威说明，不在多个位置复制同一套知识。
