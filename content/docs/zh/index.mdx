Lenso 是面向 Rust 业务系统的 Agent-ready 模块化应用框架。

从一个可部署的后端开始，按业务能力加入模块，再通过 Runtime Console
验证系统事实。只有当所有权、数据和运维边界真正稳定后，才把某个模块拆成
独立服务。

## 第一次使用

1. 阅读[快速开始](/docs/zh/quickstart)，创建一个可运行的 Lenso 应用。
2. 打开 `/console`，确认 Host、模块和运行时证据均可见。
3. 阅读[模块开发](/docs/zh/module-authoring)，加入第一个业务能力。
4. 使用项目提供的检查命令验证代码、合约和生成产物。

## 核心原则

- **模块优先。** 一个部署单元内保持清晰的业务边界。
- **Host 持有策略。** Host 负责模块装载、身份、运行时调度和证据聚合。
- **合约可提交。** OpenAPI、事件、错误和运行时合约与代码一起评审。
- **先证明，再发布。** “能够启动”不等于完成；Runtime Console 与检查结果才是可复核证据。
- **按需拆分。** 只有真实的所有权和运维需求出现时，才迁移为 Autonomous Service。
