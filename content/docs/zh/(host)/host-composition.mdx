---
title: Host Composition
description: 理解 Host 如何组合 Linked Module 并连接独立 Service。
---

Host Composition 决定哪些 Linked Module 属于当前 Host。Manifest 描述单个
Module 的纯数据贡献；组合根决定哪些 Binding、Route、Migration 与 Runtime
Handler 进入 API、Worker 和 Migration Workload。

## Linked Module

```rust
use lenso::host::prelude::*;

pub fn host_composition() -> HostComposition {
    HostBuilder::new()
        .linked_module(modules::app::linked_module())
        .build()
}
```

API、Worker 与 Migration 必须使用同一组合。Module 启用开关使用
`LENSO_MODULE_<MODULE>_ENABLED`；它只影响启动组合，不会删除既有数据。

## Service Provider

独立 Service 不进入 `HostBuilder`，也不是另一种 Module Source。通过：

```sh
lenso service install <service-manifest-url>
lenso service doctor <provider> --json
```

安装和验证 Provider。Service Manifest 声明它提供的 Module；Service 自有进程、
Store 与交付证据，Host 自有 Data Plane 与能力校验。

## 验证

修改组合后运行真实 Host 路径和目标检查，确认 Linked Module、Route、Migration
与 Runtime Handler 在 API 和 Worker 中一致。
