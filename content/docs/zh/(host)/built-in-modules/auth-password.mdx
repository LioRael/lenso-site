---
title: auth-password
description: 为 auth 认证锚点添加标识符和密码注册、登录能力。
---

`auth-password` 依赖 `auth`：

```sh
lenso module install auth
lenso module install auth-password
cargo run --bin migrate
lenso serve
```

它提供以下路由：

- `POST /v1/auth/password/register`
- `POST /v1/auth/password/login`

默认使用数据库会话令牌。若切换到 JWT 模式，应优先通过模块本地配置提供
签名 secret：

```sh
LENSO_MODULE_AUTH_PASSWORD__JWT_SECRET=<secret>
```

`user_id` 仍然是 `auth.users` 的 id；产品资料和 Console Operator 身份都
不会由 `auth-password` 自动创建。
