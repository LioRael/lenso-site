---
title: auth-anonymous
description: 添加以后可以升级为正式身份的匿名访客会话。
---

当用户需要先以访客身份进入产品、之后再绑定密码或 OAuth 身份时，安装
`auth-anonymous`。它依赖 `auth`。

```sh
lenso module install auth
lenso module install auth-anonymous
cargo run --bin migrate
lenso serve
```

创建匿名会话：

```sh
curl -sS -X POST http://127.0.0.1:3000/v1/auth/anonymous/login \
  -H 'content-type: application/json' -d '{}' | jq .
```

返回值包含 `user_id`、`session_id`、`token`、`expires_at` 和
`is_anonymous: true`。以后绑定真实凭据时仍保留同一个 auth user id，所以下游
业务数据无需迁移到新用户。
