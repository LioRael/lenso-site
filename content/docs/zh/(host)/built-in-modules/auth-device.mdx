---
title: auth-device
description: 记录设备并把设备策略关联到认证会话。
---

当登录需要记录并复用设备 id 时安装 `auth-device`。它依赖 `auth`；如果
登录入口使用密码，再同时安装 `auth-password`。

```sh
lenso module install auth
lenso module install auth-password
lenso module install auth-device
cargo run --bin migrate
lenso serve
```

密码注册和登录请求可以携带 `device_id`。提供该字段后，设备策略会记录
设备并把它关联到创建的会话。授权 Operator 可以通过受
`auth_device.devices.read` 保护的设备读取界面检查记录。
