---
title: auth
description: 安装负责用户、身份和会话的 Host 认证锚点。
---

当 Host 需要持久化应用用户和会话时，安装 `auth`。所有其他官方认证方式
都依赖它。

```sh
lenso module install auth
cargo run --bin migrate
lenso serve
```

`auth.users` 只保存稳定的认证 Actor，不保存昵称、头像、套餐、租户或组织
成员关系。产品资料应放在应用自己的表里，并通过 `auth_user_id` 关联。

模块提供开发会话和会话撤销路由。安装后，在已连接 Console 的 Modules
页面确认它已加载；授权 Operator 还可以查看用户和会话，以及执行会话
撤销、用户启用或禁用操作。

Postgres 是默认会话查询后端。如需 Redis：

```sh
lenso module install auth --profile redis-session-cache
```
