---
title: organization
description: 添加可复用的组织、角色、成员关系和邀请能力。
---

`organization` 是业务基础模块，不属于认证锚点。它依赖 `auth`，因此成员
关系可以引用稳定的 auth user id。

```sh
lenso module install auth
lenso module install organization
```

模块负责组织及 slug、组织内角色和 permission、成员关系，以及邀请的创建、
过期、接受和撤销。它还提供业务操作界面和 `has_permission`、
`accept_invitation` 等公开 Rust helper。

邀请 token 只在创建时返回一次，数据库只保存 hash。模块不发送邀请邮件；
应用应通过自己的通知链路发送邀请 URL。启用 `audit-log` feature 后，组织和
邀请变更也可以写入官方 `audit-log` 模块。
