---
title: platform-story
description: 从平台拥有的可观测性路由检查Lenso Console Story。
---

`platform-story` 为Lenso Console Story提供支持。已被平台收录
组成，不应该像应用程序模块一样安装。

它拥有：

- `/admin/runtime/stories`和Story详细路由。
- Runtime Story显示 HTTP 路由、管理操作、Provider的元数据
  调用、函数和后台工作。
- Story Console显示在 配置的 Console Service URL 下。

使用它来检查请求或工作流中发生的情况。不要放
`platform-story` 中的业务数据或特定于功能的 UI；作者正常
模块或Service。
