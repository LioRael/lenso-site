## Module

Module 是具有单一 Authoring Interface 的可安装产品能力。一份 Plan 可以多次
实例化同一 Module 包；每个 Module Instance 都有 App 内键、生命周期 generation、
配置、endpoint 与绑定。

## Capability

Capability 是版本化的深层角色 Interface。它持有稳定 Operation 与领域值，
不持有传输、部署或具体实现。Consumer 只获得 Composition 明确绑定的强类型句柄。

Operation 有三种交互形态：

- **Request**：一个终态结果；
- **Stream**：有界流、独立 half-close、取消和明确终态结果；
- **Event**：各订阅者独立有界 admission，并报告部分结果；不隐含持久化或重投。

## 绑定基数

Requirement 声明 exactly-one、optional-one 或 many provider。Resolve 在启动前
验证基数。Kernel 不选择 fallback provider，不在启动后重绑，也不发现新实现。

## Domain 与 Runtime Failure

预期领域结果保留在生成的 Capability 合约中。Runtime Failure 描述 admission、
deadline、取消、provider 失败、非法 wire value 或执行不可用。两者分离后，调用方
才能明确决定 retry 与授权策略。
