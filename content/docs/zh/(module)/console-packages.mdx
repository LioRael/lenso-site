---
title: Module Console UI
description: 通过已验证的隔离 Web 制品交付 Module 自有的 Console 页面。
---

Module 可以贡献 Console 导航和页面，但可执行 UI 不会进入 Console Shell
的 JavaScript 运行域。Manifest 只声明界面；同一个不可变 Module Release
绑定经过验证的 UI 制品。

## 声明隔离界面

在 `ModuleManifest.console` 中使用
`ConsoleSurfacePresentation::Isolated`，并将 `entry` 指向制品内的安全相对
路径，将 `bridge_protocol` 设置为 `lenso.console-bridge.v1`。

```sh
lenso module create crm --with-console-ui
lenso module dev --console-ui
```

Module Release 必须同时包含 `ConsoleUiArtifact`：`isolated_web` 格式、精确
locator 与 SHA-256 digest、入口、Bridge 协议、请求权限和 provenance。隔离
界面没有匹配制品入口时，Release 无效。

## 运行边界

Console Service 只会通过已审核的 composition operation 下载完整制品集合，
逐一校验 digest，并原子记录 composition receipt。Shell 在 sandboxed iframe
中加载页面，只向精确的 Module Release 和 UI artifact digest 授予审核通过的
Bridge operation 子集。

制品可使用 `@lenso/console-bridge` 与 Shell 交换结构化消息。它不能获得环境
凭据、深度导入 Shell 内部、使用同源存储或直接访问受管 Service。

系统中不再有 `/console/extensions/*` registry、同源 JavaScript bundle、
`@lenso/runtime-console-api` 或独立 Console package 安装命令。UI 生命周期随
普通的 `lenso module install|update|disable|remove` 和
`lenso console composition plan|apply` 完成。

当界面制品缺失、未验证或没有 grant 时，Console 会明确显示 composition
缺口，不会静默加载 package 或执行未审核的 fallback。
