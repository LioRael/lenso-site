The shortest supported path starts with one ordinary Plugin project. Rust can
produce portable Wasm plus a trusted Process implementation from the same
source; Bun uses the generated `@lenso/bun` runtime lowering.

## Prerequisites

- the `lenso` CLI;
- Rust stable with the `wasm32-unknown-unknown` target for the default scaffold;
- Bun 1.2.21 or newer only when selecting `--runtime bun`.

## Create and exercise a Plugin

```sh
lenso plugin new example.echo
cd example.echo
lenso plugin check
lenso plugin dev \
  --operation execute \
  --request-json '{"name":"example.echo","arguments_json":"{\"text\":\"hello\"}"}'
lenso plugin pack
```

Use `lenso plugin dev --watch` to rebuild and rerun after source changes. The
development build stays unoptimized; `plugin pack` performs the release build
and reopens the resulting `.lenso-plugin` archive through the same verifier used
for installation.

For TypeScript, create the equivalent Bun project:

```sh
lenso plugin new example.echo --runtime bun
```

Edit `src/plugin.ts`. The generated entrypoints own descriptor projection,
development invocation, and the production Bun server; business code does not
implement JSON-RPC or process lifecycle.

## Create an App workspace

An App is derived from one exact Host Build plus a visible `plugins/` directory.
Initialize that layout from matching Host artifacts:

```sh
lenso app init \
  --host /path/to/host \
  --host-catalog /path/to/host-catalog.json \
  --root ./my-app
cd my-app
lenso app check
lenso app show
```

Install a local bundle with `lenso plugins add`, or use exact catalog versions:

```sh
lenso plugins search echo
lenso plugins install example.echo --version 1.0.0
lenso plugins configure example.echo default --file echo.toml
lenso app check
lenso run
```

Catalog installs verify the downloaded archive digest, Manifest digest, Bundle
closure, Host target, execution class, and candidate App before replacing
Desired State. Updates retain exact archives for `plugins history` and
`plugins rollback`.

Run `lenso doctor` when setup or resolution fails. It emits human-readable
checks by default and stable JSON with `--json`.
