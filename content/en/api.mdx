## Experimental, in-progress and platform limits

- Source oRPC v2 pins prerelease `2.0.0-beta.42`; published Web 0.1.0 still uses v1.
- Core configuration and Web `/bun` are implemented source-preview APIs absent from the same-version npm artifacts.
- Log/OTel have source implementations but return registry 404 at this check. Workers uses platform-native telemetry by default; do not assume Bun SDK behavior.
- No independent Manage package/command exists. Explicit app operations are the supported entry. A configuration center, subscriptions/hot reload and Observe query CLI are not provided.
- The shipped durable task queue is PostgreSQL. D1/R2 bindings remain platform-owned and cannot be closed like Bun clients.
- The browser entry does not export startApp. Server resources, secrets and identity adapters must stay out of client bundles.
