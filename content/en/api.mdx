## Published, experimental and unavailable boundaries

- The exact packages above are published, and public entries/symbols were checked against real tarballs. Publication does not grant application authorization or deployment permission.
- oRPC v2 pins prerelease 2.0.0-beta.42; client and server must match. Native Workers tracing is a separate experimental entry, without an assumed Bun OTel SDK contract.
- Manage supplies finite-operation adapters, agent tools and an optional oRPC router. It supplies no Console UI, persistent approval/audit, scheduling, rollback or automatic config access. Trusted binding, operation admission and shared-service object policy remain required.
- A config center, subscriptions/hot reload and Observe query CLI are unavailable. Config sources are replaceable and manual resolution remains supported without Web.
- The durable queue is PostgreSQL. D1/R2 are borrowed platform bindings; Bun filesystem, DB clients and Engine do not belong in a Worker runtime graph.
- Browser entries do not export startApp. Server resources, secrets and identity adapters stay out of client bundles. Storage/Tasks have no migration export subpaths; do not guess internal imports.
