# Source-content fixture: configuration

This test record has no runtime configuration or package installation step.
It names an editable template and a development extension. A real copy would
place files in a new App-owned directory; it would not select an extension or
authorize its compiler to run.

If the App owner later selects a reviewed extension as a local Plugin, that is
a separate App change with its own build and permission checks. This fixture
does not supply a usable extension or a Host compatibility claim.
